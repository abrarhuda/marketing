# Documentation

This folder contains the project's methodology and implementation notes:

- `architecture.md` explains the data flow and reproducibility boundaries.
- `data_dictionary.md` defines source and derived fields.
- `experiment_design.md` documents the retrospective statistical plan.
- `ab_testing_results.md` explains the A/B test output.
- `machine_learning.md` documents feature selection and model evaluation.
- `revenue_analysis.md` explains the bootstrap revenue analysis.
- `uplift_modeling.md` and `uplift_evaluation.md` explain the T-Learner and
  randomized policy evaluation.
- `visualization_report.md` provides chart captions and interpretations.
